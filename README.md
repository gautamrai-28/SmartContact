# SmartContact

SmartContact is a simple C++ contact management system built using Object-Oriented Programming and File Handling.

## ✨ Features
- Add, edit, delete, and view contacts
- Search contacts (case-insensitive)
- Sort by name or phone number
- Auto-save after every change

## 💻 How to Run
1. Open the project in any C++ IDE (like Code::Blocks, VS Code, or Dev C++).
2. Compile and run the `SmartContact.cpp` file.
3. All data is stored locally in `contacts.txt`.

## 📁 Technologies Used
- C++ (File handling, OOP, STL)
